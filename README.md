# 🐍 Змейка — PWA

Классическая «Змейка» в виде Progressive Web App.  
**Разработчик:** SKLN · **Год:** 2026 · **Версия:** 1.0

## Возможности
- 🔄 Проход сквозь стены (wrap-around) — выход за край → появление с противоположной стороны
- 💾 Локальное сохранение прогресса (localStorage)
- 👥 Многопользовательский режим — несколько профилей с личными рекордами
- 📤 Экспорт / 📥 Импорт сохранений в JSON
- 🔊 Звуковое сопровождение (Web Audio API, без внешних файлов)
- 🎨 4 темы оформления: Тёмная, Светлая, Матрица, Океан
- 📱 Адаптивный интерфейс + свайпы и D-pad для мобильных
- 📴 Офлайн-режим через Service Worker
- 🎬 Анимированная заставка 10 секунд

## Управление
- **ПК:** стрелки / WASD, `Space` — пауза
- **Мобильные:** свайпы по полю или экранные кнопки
